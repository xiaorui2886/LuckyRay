# LuckyRay

把素材、笔记与灵感连接起来。

LuckyRay 是面向创作者的本地优先工作空间，让素材整理、Markdown 笔记、画布和 AI 辅助创作自然衔接。

## 创作空间

- **素材库**：通过文件夹、标签和搜索整理图片、视频与创作文件，支持原文件及 CSV 元数据清单导出。
- **知识库**：使用 Markdown 记录笔记，以链接和关系图谱连接想法。
- **画布**：自由组织文字、图片、视频与创作内容。
- **AI / LightSeek**：连接你选择的模型服务，在授权范围内使用资料辅助创作。
- **插件**：按需扩展功能，安装时查看权限，由你决定允许访问的资料。

桌面版面向 Windows 10/11 x64。应用可免费使用；第三方模型、搜索等服务的费用由对应服务商决定。详见[使用与许可说明](LICENSE.md)。

## 开发与社区

SDK 1.0.0 提供 API 类型、创建/检查/打包工具，以及素材清单、配色、笔记提纲、画布导出四个教学示例。请先阅读[版本兼容说明](docs/compatibility.md)。

插件目录目前开放提交，尚无上架的第三方条目。现阶段通过 GitHub 审核、手动下载并在应用内安装；不提供自动安装或自动更新。
