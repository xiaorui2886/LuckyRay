# LuckyRay 官方可选 MCP 插件

把网页 AI 与你明确选择的素材库、知识库连接起来：搜索和读取素材，导入图片、PPTX 等文件，把 Markdown 新建为笔记。默认不安装完整运行包；在 LuckyRay 社区点击「添加」后自动下载、校验并安装本机组件，无需另装 Node 或输入命令。

**0.1.1 修复**：修复 Windows 中文或其他 Unicode 安装路径导致的桌面实例发现失败。需要 LuckyRay **1.9.8** 或已包含 0.1.1 可信组件清单的新版桌面；1.9.7 固定旧版校验值，不能直接替换其中的组件文件。原 0.1.0 发布保留，不覆盖旧附件。

**0.1.2 修复候选**：明确 Markdown 的目录必须是授权知识库中已存在的目录；不填目录则保存到根目录。素材库文件夹不是知识库目录，插件不会自动建目录。配合已包含目录预检的桌面修订，目录不存在会明确反馈，不再误当未知保存结果。旧未知结果的保护保留，不要删除 pending、改请求编号或盲目重试。本候选未公开发布，需桌面中对应版本的可信清单，不能直接替换已安装脚本。

**0.1.3 收口候选**：减少 Windows 桌面实例核对的等待，仍严格核对进程、端口、创建代次与授权签名，不缓存或放宽实例身份。配合本轮桌面后端修订，Markdown 同请求重试会重新校验文件内容与固定目标，而不把附件临时下载网址当成稳定身份。内容或目标不同仍拒绝；已有未知请求保护不变。本候选仅用于私库联验，不是公开发行。

## 1. 添加并授权

1. 使用包含官方 MCP 下载入口的 Windows x64 LuckyRay 新版，进入「社区 → 插件 → LuckyRay MCP → 添加」。下载失败可重试；校验失败的包不会安装。
2. 选择要开放的素材库与知识库，确认范围后点「一起授权」。这是一个共同开关，两库一起开启、一起关闭，授权有效期在界面显示。
3. 授权固定绑定所选两库。切换 LuckyRay 当前库不会改变授权目标。插件允许搜索、读取、导入素材和新建 Markdown，不开放终端、Agent 控制，也不会修改或删除已有笔记。

## 2. 在官方网页准备独立隧道

打开 [OpenAI 隧道管理页](https://platform.openai.com/settings/organization/tunnels)，为此插件创建独立隧道，关联你的 Platform 组织和要使用的 ChatGPT 工作区。不要覆盖私人 Agent Gateway 的隧道。

创建/管理隧道需要相应的管理权限，运行和选择隧道需要使用权限；ChatGPT 添加自定义 MCP 的权限另由工作区控制。以 [OpenAI 官方说明](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels)及你的账号实际入口为准。

准备两项不同内容：

| 内容 | 在哪里填写 | 含义 |
| --- | --- | --- |
| Tunnel ID（完整的 `tunnel_…`） | LuckyRay 的 Tunnel ID 输入框 | 隧道标识，不是网页网址或 API Key ID |
| 运行 API 密钥 | LuckyRay 的安全输入框 | 运行隧道所需凭据，不是 Tunnel ID |

示例仅为格式占位，不可使用：`tunnel_0123456789abcdef0123456789abcdef`、`<你的运行 API 密钥>`。不要把密钥发进聊天、截图或反馈报告。

## 3. 在 LuckyRay 连接

1. 在 MCP 面板填写 Tunnel ID 和运行密钥，点「保存连接配置 → 连接」。密钥按当前 Windows 用户加密保存；已有密钥时留空保持原值。
2. 需要下次打开软件自动连接，可开启「随 LuckyRay 启动连接」。它不创建 Windows 服务或系统开机任务。
3. 「隧道就绪 · 等待网页调用」表示本机链路已就绪；网页调用真正成功后才显示「已连接」。保持 LuckyRay 打开。

## 4. 网页 ChatGPT / Dot 使用

ChatGPT 的 [Plugins 页面](https://chatgpt.com/plugins)中选择添加自定义 MCP server，连接类型选 Tunnel，选择或粘贴同一 Tunnel ID，按网页要求确认身份验证和风险提示并创建。隧道未显示时检查工作区关联和账号权限。无需把运行密钥发到对话，也不要把 `localhost` 当成云端可访问地址。

连接后选中该插件，先让 AI「搜索授权素材库中的图片」。再上传一个 PNG 或 PPTX，要求导入授权素材库并返回文件名、类型和 assetId；重复导入同文件应返回相同 assetId。上传中文 `.md` 时要求导入授权知识库并返回 noteId，再检索、读取正文。同一导入请求重试不会重复建笔记，也不会覆盖已有笔记；Markdown 引用的外部图片/附件不会随正文自动导入。

Dot 仅在当前版本和账号提供受支持的 Tunnel/自定义 MCP 入口时使用同一独立隧道，按其实际界面选择插件。本版真实网页证据来自 ChatGPT；Dot 未单独验收，不承诺所有账号或网页客户端都有此入口。这是 LuckyRay 社区插件上架，不代表已上架 OpenAI 公共插件商店。

## 5. 更新、停止与常见问题

- 已安装 0.1.0 或候选版：先正常退出并安装 1.9.8 小修版，再在社区「停止连接 → 更新插件 → 连接」。原两库授权、加密运行密钥和自动连接选项会保留，无需重新授权。新版桌面不会默认捆绑此运行包。
- 红色 Tunnel ID 提示：填完整 `tunnel_…`，不要填 API 密钥、Key ID 或网页地址。保存按钮不可用时先停止连接，检查 ID 与首次运行密钥。
- 另一条隧道正在运行：确认原连接的用途并安全停止后重试。插件不会结束未知进程或重绑私人隧道。
- 本机已就绪但网页不可用：检查网页是否选中了对应插件，以及隧道工作区关联、权限与官方服务状态。不能用本机就绪代替网页成功。
- 关闭访问：点「关闭授权」，素材与知识库访问同时停止。更换授权目标须通过界面重新确认；不要删除数据库或复制凭据来修复。
- 卸载：社区面板「卸载插件 → 确认卸载」，停止本插件并移除其运行包、授权与连接配置，素材和笔记保留。取消卸载不会改变配置。
