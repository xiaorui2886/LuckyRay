关于

产品信息、技术栈与致谢

LuckyRay v0.1.0
1.0 收尾 Tauri 2.x 本地优先

LuckyRay 是一个为创作者设计的个人素材 + 知识管理桌面应用。它把 Eagle 的素材管理、Obsidian 的双向链接和 AI 助手融合在一个极简界面里 —— 让你的素材、笔记和想法自然地连接起来。

1.0 版本基于 Tauri 2.x + React + SQLite 构建，所有数据本地优先（fallback 双轨：浏览器侧用 localStorage，桌面侧用 SQLite）。

技术栈

模块技术版本
运行时Tauri2.x
前端React + Vite18.x / 5.x
UI 框架原生 CSS Variables—
笔记编辑器contenteditable (Tiptap 计划中)—
数据库SQLite (rusqlite)3.x
AIDeepSeek / OpenAI / Anthropic兼容 OpenAI 协议
图谱D3-force + Canvas—
全文搜索SQLite FTS5 (unicode61)—

致谢

灵感来源：Eagle 的素材管理范式、Obsidian 的双向链接哲学、Notion 的块编辑器，以及Raycast 的命令面板交互。框架选择：Tauri 团队、React 社区、Tiptap 编辑器团队。
