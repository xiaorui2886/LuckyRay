# 插件兼容性

SDK 版本与 LuckyRay 桌面版本分别编号。当前 SDK 为 **1.0.0**，接口版本为 **API1**。

| 范围 | 说明 |
| --- | --- |
| Windows 桌面 API1 | 提供素材、知识库、画布和插件自有数据接口。 |
| v1.9.4 | SDK 方法已与该版本源码对照；此公开 SDK 包未完成新的端到端安装运行验证。下载状态见[下载说明](downloads.md)。 |
| 最低版本声明 | CLI 默认 `minHostVersion: 1.9.2` 仅是声明，不代表所有旧版或新版均已测试。 |
| 页面入口 | 需要支持 `page` 贡献的宿主；不支持的旧版可能拒绝安装。四个教学示例不依赖页面入口。 |
| 手机、Collector、DSH 插件 | 属于不同接入体系，本 SDK 不自动适用。 |

具体方法、输入输出与错误码见 [API 类型](../sdk/index.d.ts)及[开发指南](../sdk/README.md)。

## 权限与运行

插件权限与每次运行的对象选择分别控制。写入需要宿主确认；旧 revision、未授权对象或失效会话可能被拒绝。插件运行有资源和时间限制，不提供任意网络、文件系统、进程或模型密钥访问。

写入结果未知时，请核对应用回执和实际资料，不要自动重复提交。

## 声明支持的版本

插件作者须填写实际测试过的准确宿主版本。仅通过 CLI 检查和打包时，使用 `authoring-only`，测试宿主列表留空；完成正式宿主安装、授权和功能验证后，才使用 `host-tested` 并附脱敏记录。
