# LuckyRay 桌面版 1.9.9

本版集中更新画布创作、Canvas Agent 与本地 3D 导演台，内置 LightSeek 引擎升级至官方 DeepSeek Harness 0.2.1-rc.3，并修复旧版覆盖安装后 LSH 无法启动及手机连接端口不可用时的恢复流程。

唯一官网：[luckyray.me](https://luckyray.me)。Windows x64 安装包：`LuckyRay_1.9.9_x64-setup.exe`。Collector 继续沿用独立发布的 1.9.6，不随桌面安装自动更新。

## 画布、参考与脚本分镜

- 完善画布素材目录树、文件夹浏览、媒体预览和内容搜索定位，将参考包、创作模板、结果收纳连接到现有画布。
- 增加脚本与分镜工作区，提供镜头脚本、分镜创作、连贯脚本三种视图；支持镜头字段编辑、参考素材增减、候选结果、脚本导入和导出准备。计划时长用于脚本规划，不等于生成视频的实际时长。
- 改善参考图片与视频悬停预览、视频自动播放和缩略图标识，修正图片裁切、文本重复以及预览尺寸问题。
- 完善参考排序、拖拽裁剪、结果定位和多节点整理；调整框选后的操作栏与右键菜单。
- 改善脚本适宽、字段保存、摘要展开与收起、分界线和滚动体验；指定区域隐藏滚动条并保留滚动。
- 将创作工具弹窗限制在所属画布范围，适配窗口大小变化；修复展开文本编辑时 Esc 返回以及中文输入法焦点和工具栏操作。
- 优化脚本分组与导演台送出分镜的间距，保留已有节点位置。

## Canvas Agent

- 增加与当前画布协作的 Agent 工作台，提供模型选择、引用内容、对话历史、任务轮次和过程回看。
- 支持真实创作工具、单项及批量编辑、结果读回，以及脚本、分镜和导演台的专门操作；保持参数、数量、版本 revision 与权限校验。
- 修复官方模型所需的创作工具根参数声明，向模型返回字段级校验错误；区分工具业务失败和成功回执。不同模型及中转服务的兼容性仍以实际能力为准。
- 完善请求失败的脱敏原因展示，避免把一次模型请求失败直接归类为整个连接不可用。
- 按整轮维持任务过程：发送时展开，工具调用期间保持；保留手动开关，结束时只自动收起一次，并可再次展开。
- 接入 LSH 原有状态组件、工具计时、详情和公开思考流；仅展示实际收到的公开思考，不以普通回复推测思考内容。
- 运行状态沿用原有文字流动光效，完成后停止，并遵循减少动效设置。黑洞入口支持拖动、锁定和恢复默认位置。
- 修复快速流式回复时正文与结果卡变化引起的上移闪动；保留当前回复全文，手动上滑看历史时暂停跟随，返回底部后继续跟随。

## 本地 3D 导演台

- 新增人物、基础几何布景和场景预设，支持机位、灯光、焦距、画幅与镜头管理，保存后可重新打开。
- 支持人物白膜与原色、关节旋转、手脚 IK、骨盆、姿势预设、镜像、重置，以及自定义姿势保存和应用。
- 支持撤销、重做、克隆后独立编辑、对象锁定和操作取消。
- 增加中键环绕、Shift＋中键平移，完善镜头内对象移动旋转、左键框选、参数拖动、Shift 细调及镜头滚轮交互。
- 摄像机线框可选取、移动、旋转与保存；补充坐标原点、地面、尺寸、旋转缩放、实际几何底部高度和离地距离的读回信息。
- 提供本地 GPU 截图及送入画布、脚本分镜的工作流。保存镜头与捕获后送入是两个步骤；不自动贴地、不把场景文字描述当作截图，也不需要调用图片生成服务完成本地截图。

## LightSeek / LSH 与安装启动

- 随包引擎由 1.9.8 的 0.1.7-rc.2 更新至官方 DeepSeek Harness 0.2.1-rc.3；LSH 引擎本身仍是上游候选版本。
- 更新宿主、适配器和配套资源，保留既有对话、工作区和授权；完善原文件输入、草稿恢复、原生重启确认，以及手机侧栏、抽屉和能力目录配套。
- 修复旧版覆盖安装后，新旧引擎文件混入同一目录造成的启动失败。新版使用确定的自有资源目录，保留旧资源备份，继续严格核验完整资源、摘要、签名和事务状态。
- 完善真实 Node/宿主进程归属识别与更新退出保护，不执行旧平铺目录或备份目录中的运行时。

## 设置、素材库与笔记

- 完善画布媒体供应商、模型和可选参数配置，空参数不再显示多余分隔符、单位或 undefined；增加 CogVideoX-Flash 接入及本机 ComfyUI 的连接准备、只读状态检查入口，ComfyUI 此阶段不执行生成工作流。
- 区分生成任务的本地排队、提交中、供应商已受理和失败，取得供应商任务 ID 后才显示已受理；保留任务恢复信息，改进脱敏错误分类，避免失败后残留“任务已创建”。这不代表每个供应商或媒体生成场景均已实测成功。
- 调整全局设置和主题预览、下拉菜单底色、焦点及选中状态，修正白底菜单和重复高亮。
- 完善素材库及画布弹窗布局、目录导入、缺失记录检查和恢复入口，以及切库、目录变化后的列表刷新。
- 改善笔记保存回执与外部刷新协调，减少自身保存引起的反复冲突提示；保留真实外部修改的冲突保护。
- 改善中文输入法与焦点处理，以及笔记编辑中选区的文字对比。个别长笔记的输入延迟仍需继续观察。
- 增加已保存多库、按库范围的手机服务与显式信任模式；统一 Notes 桌面配套补齐目录创建、精确路径导入计划和副本清单/验证。入队与最终保存分别确认。

## 手机连接恢复

- 设置页按实际监听结果区分端口占用、绑定拒绝、接口不可用与未知错误，不把普通绑定失败直接认定为防火墙问题。
- 原地址不可用时，用户可在“设置 → 连接手机”确认选择可用端口。恢复限定在原网卡、有界尝试，成功后保存实际端口，不抢占其他实例，也不自动改防火墙或系统保留区。
- 提供已配对手机的地址恢复二维码；兼容手机端核对原实例、证书与既有配对后更新地址，保留原有授权。用户已报告真实手机重连实测通过；不据此承诺所有手机和网络环境均已覆盖。
- **待补：主导航栏手机快捷弹窗尚未接入上述恢复入口。目前请从设置页操作。**
- 本桌面发行不包含测试手机 APK；手机统一知识库的后续接入由手机版本独立交付，不混入本次桌面安装包。

## 使用与验证边界

- 支持 Windows 10/11 x64。更新前正常保存并退出旧版，重要资料请保留独立备份；不建议用旧程序直接打开新版数据。
- 保留 1.9.8 的签名更新器与官方 MCP 0.1.1 中文路径修复，这两项不是 1.9.9 首次新增。
- 旧版覆盖、新装及退出重开已完成限定的真实 Windows 安装验证；源码检查、安装验证、用户体验及手机测试分别记录，不代表所有历史数据、输入法、GPU、模型路由或故障组合全部通过。
- AI 与联网功能按需配置。供应商的权限、配额和费用以实际服务为准；本版不承诺固定 token 节省比例或媒体生成免费。
- 安装器具有原生产公钥可验证的更新签名，**Windows Authenticode 仍未签名**。更新器签名与 SHA-256 不能替代 Windows 代码签名。
- LuckyRay 自有源码按公开仓库许可提供，第三方组件保留各自许可。请同时保留正式发行页列明的第三方许可、源码和构建材料。
