# LuckyRay 桌面版 1.9.10

本版更新画布创作、视频播放、Canvas Agent 与 LightSeek，并改善图谱、笔记、素材库和社区的日常操作。

## 画布与创作

- 新增独立 ComfyUI 工作流卡片，支持导入模板、选择输出、提示词映射、常用参数、保存与导出，并保留通用 H3、短剧工作流预设和 API 图片／视频卡片。
- 完善文字、笔记、单图和多图引用，保留引用顺序、任务历史、结果回填、保存和下游应用。任务受理结果不明确时不自动重复提交。
- 按工作流实际能力提供尺寸、种子、LoRA、采样和放大选项。停止本地跟踪与停止 ComfyUI 服务端生成分别处理。
- API 卡片可直接选择已保存连接中的模型，模型与连接保持对应，减少来回切换设置。
- 统一紧凑工具栏、参数弹层、尺寸选项和参考包缩略图。图片精修移至图片卡片，成品导出置于选择工具栏。
- 移除豆包网页连接器，保留历史结果；火山官方 API 与通用并发继续保留。

## 视频播放与素材引用

- 更新 LGPL libmpv／FFmpeg 播放组件，支持组件实际提供的常见格式及 HEVC 10 位原文件播放，不改写原文件。
- 修复从素材库引用视频后的初始元数据、封面和尺寸，减少封面切换带来的黑边与比例变化。
- 统一视频外框与控制条，修复移动和节点交叠时视频画面穿透其他卡片的问题。交叠／移动使用最高约 15fps 的同层帧桥，无遮挡静止后恢复原生画面。
- 保留悬停静音、手动声音控制、单卡发声，以及离开画布或隐藏后的停止行为。
- 修复手机原文件接口的 MIME 判断，显示名没有扩展名时仍按真实文件类型提供内容。

## Canvas Agent 与 LightSeek

- 内置 DeepSeek Harness 0.2.2-rc.1 与 Node 24.22.2，更新 LSH 资源适配并修复白屏问题。
- 修复 Canvas Agent 与新版 SDK 的工具执行接口兼容问题，保留工具作用域、参数、版本和权限校验。
- 修复失败详情未被宿主正确传递的问题，使失败终态能够正常显示；错误详情继续限长、脱敏并校验字段。

## 图谱、笔记、素材与社区

- 修复图谱在极短鼠标事件间隔下异常甩动，保留拖动惯性和最终位置保存。
- 将笔记附件轮询移出原生窗口线程，隐藏时暂停、返回后恢复；修复切库后图谱标签页未及时更新。
- 完善 TXT 正文预览与截断提示、素材封面、格式卡和音频声波，保留原文件打开与导出。
- 增加空白处及卡片间隙框选，恢复视频拖入文件夹和其他软件的操作。
- 统一社区分类与二级页面，刷新时保留已有内容，减少页面重建造成的闪烁。
- 精简素材库管理和手机连接页面，统一设置、自适应布局与存储总览。已撤销设备从列表隐藏，原配对记录继续保留。
