# LuckyRay v1.9.4

桌面下载尚未开放，开放后以 [Releases](https://github.com/xiaorui2886/LuckyRay/releases) 附件为准。

[Collector 1.9.4 历史版本归档](https://github.com/xiaorui2886/LuckyRay/releases/tag/collector-v1.9.4)已开放下载（预发布），需搭配兼容版本的 LuckyRay 桌面端使用。归档包的运行文件保持 1.9.4 原样，不代表当前开发进度或最新功能。

## 主要变化

- 素材来源页面、原文件导出与 CSV 元数据清单
- 图片对比和日常浏览体验改进
- 桌面与手机连接入口及按范围授权
- LightSeek 随包引擎更新至 DSH 0.1.7-rc.2
- 素材、知识加入会话草稿的反馈与防重复处理
- 第三方插件兼容检查与恢复，以及通知和导出反馈调整

资料加入会话草稿不会自动发送给模型。

## 使用注意

- 支持 Windows 10/11 x64。原安装器未作 Authenticode 签名，文件哈希不能代替代码签名。
- 安装或升级前请备份重要资料，不建议旧程序直接打开新版数据。
- AI 需要自行配置模型服务。手机连接能力需匹配移动端版本和授权范围。
- 首次进入 LightSeek 可能较慢；本版未配置独立引擎在线更新源。
- 网页采集受浏览器受限页面、登录权限和 DRM 等条件影响。
