# LuckyRay 1.9.8 · 自动更新与 MCP 中文路径修复

唯一官网：https://luckyray.me

## 本版更新

- 正式启用带签名校验的应用内自动更新。下载完成后可选择立即安装并自动重新打开软件，或安排下次启动时安装。
- 更新前正常保存笔记并退出 LSH；升级后保留原有笔记、设置及社区 MCP 授权。修复 LSH 已停止后仍可能阻止更新的问题。
- 配套官方网页 MCP 0.1.1，修复中文安装路径下的连接绑定问题。MCP 仍是社区内按需安装的可选组件，两库统一授权。
- Collector 保持 1.9.6，附件与上一版完全相同；桌面更新不会自动替换浏览器插件。LSH 随包版本保持 0.1.7-rc.2。

## 从旧版升级：首次仍需手动安装

原公开版 1.9.7 及更早版本未配置本次正式自动更新信任，请先从本页或官网下载 1.9.8 安装包，正常退出旧版后手动安装一次。安装完成后，后续受支持的新版本可使用应用内自动更新。不要把测试用的修补版 1.9.7 当成原公开版。

## 验证与边界

本次固定安装包已在独立 Windows 环境完成“立即更新”和“下次启动时安装”两条连续实装链：保存待写入笔记、正常退出、被动安装、自动启动新版、正文/设置/合成 MCP 授权读回；中文空格路径、安装语言保持、错误平台及重复/旧版本拒绝均通过。测试采用受控 HTTPS 更新源；正式公开下载地址在发布后另行检查。

这些验证不代表所有用户设备、旧资料、输入法或外部隧道配置均已覆盖。安装前请备份重要资料，不混用开发版与日常版数据。

## 下载与安全

- Windows x64 安装器：LuckyRay_1.9.8_x64-setup.exe
- 浏览器插件：LuckyRay-Collector-1.9.6.zip
- latest.json 与 .sig 供应用更新器校验使用；普通用户不必手动配置。
- 安装器未做 Windows Authenticode 代码签名。更新器签名与 SHA-256 校验不等于 Windows 代码签名，请勿关闭安全软件或绕过安全检查。
- 官网保持点击直接下载安装包。
